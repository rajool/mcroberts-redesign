# Configuration changes for the new information architecture

The new site structure (design/ia.json, explained in design/ia.md) is configuration: menus, URL aliases, redirects
and block placements. No node body, paragraph, media or field changes. Everything here is reversible.

| File | What it holds |
|---|---|
| [menus.md](menus.md) | The link trees of menus `main` (7 items, columns, links), `utility`, `footer` and `hub-links`, as tables |
| [urls.md](urls.md) | The 28 aliases that change (old → new) and the 5 retired pages |
| [redirects.csv](redirects.csv) | The same list as source → destination rows for the Redirect module (301) |
| [blocks.md](blocks.md) | The block placements of the `mcroberts` theme: what changes after `drush theme:install`, and why |
| [apply.php](apply.php) | Optional `drush php:script` that does all of the above, with a dry run, a log and `--rollback` |
| [ia-data.php](ia-data.php) | The data apply.php reads (generated from design/ia.json) |

`menus.md`, `urls.md`, `redirects.csv` and `ia-data.php` are generated by `tools/package_drupal.py` from
`design/ia.json`; edit the JSON and re-run it, never these files.

Order on a staging copy:

    drush theme:install mcroberts                        # while rsd_sites_barrio is still the default: copies the blocks
    drush php:script themes/custom/mcroberts/config-changes/apply.php                 # dry run: read the plan
    drush php:script themes/custom/mcroberts/config-changes/apply.php -- --apply      # aliases, redirects, menus, blocks
    drush config:set system.theme default mcroberts
    drush cache:rebuild

`--retire` with `--apply` also unpublishes the five retired pages (two copies of Information, an empty page, an
empty PAC page, a duplicate news post) and removes their aliases, so their redirects answer.
`-- --rollback` undoes everything the script logged; switching the default theme back is one setting.

By hand instead: *Structure → Menus* (menus.md), *Configuration → URL aliases* and *URL redirects* (urls.md),
*Structure → Block layout → McRoberts* (blocks.md). Without the Redirect module, keep each old alias as a second
alias of the same node, as design/ia.md describes.
